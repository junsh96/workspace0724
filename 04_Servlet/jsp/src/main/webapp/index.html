JSP

HTML 문서 안에서 java코드를 직접 작성할수 있는 기술이다.
- servlet에서 응답화면(HTML)을 만든느 복잡한 과정을 단순화.
- 비즈니스 로직은 servlet에서 , 화면(view)는 jsp에서 담당. -> 역활 분리(MVC패턴의 기초)
- 내부적으로는 JSP -> Servlet으로 변환후 동작. - 내장 객체 제공 : request(요청정보를 저장해둔 객체), response(응답에 필요한 정보를 저장해둔 객체), session(브라우저 별로 만들어둔 서버 저장소)등

JSP페이지 내에서 자바코드를 기술할 수 있는 기능

  • 스크립틀릿 : <% 자바코드 %>
    JSP에서 자바코드를 기술하기위한 가장 기본적인 방법.
  • 표현식(출력식) : <%= 변수 %>
    자바에 저장되어있는 값을 화면상에 출력하기 위한 방법

JSP 지시어 <%@ page | include | taglib 속성=값 ..... %>

JSP페이지 전체에 영향을 주는 속성. 설정을 선언할때 사용.

  1. Page지시어 : JSP페이지 처리에 필요한 속성을 지정하는데 사용.
    • language : jsp에서 사용할 언어
    • contentType : 해당 페이지의 형식, 문자셋
    • pageEncoding : JSP페이지 내에서 기록된 java 코드의 인코딩
    • import : 자바의 import와 동일 외부 라이브러리 참조
    • errorPage : 해당 jsp상에 오류가 발생했을 경우 보여줄 임시 페이지
  2. include 지시어 : 현재 jsp상에 또다른 jsp를 포함시켜 사용할수 있는 지시어.
  3. taglib 지시어 : jsp기능을 좀 더 확장시킬 수 있는 추가적인 라이브러리를 등록하는 지시어,
