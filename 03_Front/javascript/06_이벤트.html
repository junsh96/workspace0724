이벤트

1. 이벤트 모델의 종류

고전 이벤트 모델

특정 요소객체를 가지고와서 해당 요소의 이벤트 속성제 접근한 후
이벤트 핸들러를 연결하는 방식
이벤트를 제거할수도 있다. (element.onclick = handler;) 동일한 이벤트 속성에 여러개의 이벤트 핸들러를 연결할수 없다. -> 한개만 등록 가능.


인라인 이벤트 모델

요소 내부에 직접적으로 이벤트 속성을 제시해서 실행할 내용을 정의하는 방식
따로 script코드에 작성된 함수를 호출하는 방식. -> js와 html이 섞임 -> 유지보수가 어려움.

표준 이벤트 모델

w3c(웹 표준 국제 기구)
공식적으로 지정한 이벤트 모델
element.addEventListener('이벤트명',이벤트 핸들러 함수);
하나의 이벤트에 여러개의 핸들러를 등록할수 있음. -> removeEventListener() 이벤트 제거. 동일한 함수의 참조값을 전달해야 한다.
